Detailed Description

Indicates that the controller completed the CS handover procedure because synchronization was lost or the configured maximum procedure count was reached.

When this event is sent, the configured CS parameters are removed and the associated connection analyzer handle is deallocated. This event is intended for the CS Follower role.
