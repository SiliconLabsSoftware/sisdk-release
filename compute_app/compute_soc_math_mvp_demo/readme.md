# Demonstration of math functions that are using the MVP

This is a demonstration of how to use math functions that are accelerated by using the MVP.

## Requirements

Silicon Labs board with a device that has MVP support:

- **EFR32:** BRD2601B (xG24), BRD2608A (xG26), BRD2608B (xG26)
- **SiWG917:** BRD2605A, BRD4338A

## Running the demo

1. Generate the project for your board (for example `brd2601b`, `brd2608a`, `brd2608b`, `brd2605a`, or `brd4338a`).
2. Build and flash the application.
3. Open a serial terminal on the board VCOM port (115200 baud).
4. Reset the board and observe the MVP math demo output on the serial console.
