## Purpose / Scope

This project is a minimal C configuration with no application logic. Use it as a template to create a new project: add the components you need in the project configurator, implement your code, and build. It is useful when you want to start from scratch rather than modifying an existing demo.

## Prerequisites / Setup Requirements

**Hardware**
- Any Silicon Labs kit supported by the Gecko Platform SDK.

**Software**
- Simplicity Studio 5 (or later).

## Steps to Run Demo

1. Open the project in Simplicity Studio (or create a new project from this example).
2. Add the components and source code you need.
3. Build the project, connect your kit, and flash the application.
4. Run and debug as needed.

## Troubleshooting

- **Build errors:** Ensure the correct target part and board are selected; add any required components (e.g. clock, GPIO) for your application.
- **Flash errors:** Verify the kit is connected and recognized by Studio; check that the target matches your board.
