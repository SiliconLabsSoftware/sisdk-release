# Zigbee 4 Switch


This application demonstrates the functionality of a light switch operating on a Zigbee 4 network. This application leverages features in the R23 version of the PRO Core stack, such as Network Commissioning and Dynamic Link Key, as well as routines defined in the BDB 3.1 specification. The Zigbee 4 switch is backwards compatible with a Zigbee 3.0 network, and it uses new Zigbee 4.0 features when joining to a network that is also using Zigbee 4.0.

The current debug printing settings in these applications are only for the purpose of aiding users in understanding and debugging this sample scenario. Debug printing should be turned off in order to save code size on a final product.
